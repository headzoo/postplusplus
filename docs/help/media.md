# Media

The Media library is your organization’s store of images and videos for posts. Open it from **Media** in the main navigation, or from the post composer via **Insert Media** (**Media Library**).

## What the Media library is

Upload once, then reuse assets across the [Calendar](/help/calendar#scheduling), [Agent](/help/agent#attachments), and composer. The same picker opens as a modal when you’re writing a post.

## Upload and search

- Click **Upload** or drag and drop files onto the library.
- You can select multiple files; the total for one upload session is capped at **1 GB**.
- Allowed types: images and **mp4** video (the composer picker may restrict to images-only or video-only).
- Search with **Search by file name**. Empty library: **You don't have any media yet** with the same upload guidance. No matches: **No media matches your search**.
- Browse with **Previous** / **Next**.

## Edit media settings

Hover a thumbnail and open **Settings** (**Media Settings**):

- **Alt Text (for accessibility)** — describe the image or video.
- **Generate alt text with AI** — available when your plan includes AI; not used for mp4.
- For video: **Create Thumbnail** / **Edit Thumbnail**, scrub frames, **Select This Frame**, or **Clear Thumbnail**.

Save with **Save Changes**, or **Cancel**.

When you attach an image that has no alt text and AI is available, you may be asked **Generate alt text?** (**Yes, generate** / **No thanks**). An **ALT** badge on the grid means alt text is already set.

## Use media in posts

- On the library page, hover and click **Post** (only if you have connected channels). You may be asked to **Select a Set**, then the post editor opens with the asset attached.
- While composing, use **Insert Media**, select items, then **Add selected media**. Reorder attachments on the strip; open settings or remove per item.

Without connected channels, **Post** stays hidden on library thumbnails.

## Design, memes, and GIFs

These tools live mainly in the post composer media strip:

- **Editor** — opens the design canvas (**Media Editor**); finish with **Use this media**.
- **Create meme** — **Meme Generator**: search templates, fill **Text 1** / **Text 2**, **Generate meme**, then **Save to media**.
- GIF picker — **Search GIFs** (powered by GIPHY); select a GIF to bring it into your media flow.

## Import from other tools

Use **Import** (**Import From**) when third-party media integrations are connected. Browse the provider, select items, then **Import Selected**. Success toast: **Media imported successfully**. Empty provider: **No media found**.

## Limits and tips

- Prefer **mp4** for video; other formats may be rejected.
- Session upload total is **1 GB**, not “unlimited files.”
- AI alt text and some design features depend on your plan.
- Delete with **Delete** (confirm before removing). Deleting from the library does not automatically explain effects on every scheduled post—check posts that used that asset if you’re unsure.
